# Assets

This folder contains the Sam Codex black and gold profile visual system.

Generated files:

- `banner.png` - 1280x640 GitHub hero banner.
- `profile.png` - transparent profile asset with gold rim light.
- `logo.svg` - Sam Codex monogram logo.
- `divider.svg` - black and gold section divider.
- `about-vscode.svg` - VS Code style About Me section.
- `animated-terminal.svg` - animated terminal and cursor.
- `animated-stats.svg` - animated black and gold statistic cards.
- `animated-quote.svg` - animated developer quote card.
- `animated-header.svg` - animated brand header.
- `animated-gradient.svg` - animated black and gold gradient strip.
- `animated-tech-icons.svg` - animated technology icon row.
- `animated-wave.svg` - animated black and gold wave.
- `background.png` - reusable developer dashboard background.

Replace `profile.png` with the final processed portrait when the portrait source file is available.
