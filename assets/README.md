# Assets

This folder contains the profile visual system.

Generated files:

- `banner.png` - 1280x640 black and gold GitHub profile banner.
- `profile.png` - transparent profile image slot with gold glow.
- `logo.png` - Sam Codex monogram logo.
- `background.png` - reusable black/gold dashboard background.

Replace `profile.png` with the final processed portrait when the portrait source file is available.
